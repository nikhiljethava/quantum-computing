# Hardware Access

Quantum Foundry is an independent personal project and is not an official Google product.

> Google quantum hardware access is restricted to approved groups. Quantum Foundry is simulation-first unless approved access is configured.

## Default Behavior

Quantum Foundry is simulation-first. The public app does not expose a public QPU runner and should not imply general access to Google quantum hardware.

## What Hardware Access Means

An approved-access hardware path would require explicit configuration, access controls, service credentials, clear UI labeling, and conservative documentation.

## Required Labels

Use:

- “Approved-access hardware path”
- “Learn hardware path”
- The exact hardware disclaimer above

Avoid:

- “Run on Google hardware”
- “Production QPU”
- “Public QPU access”
- Unqualified benchmark or advantage claims

## FAQ

**Can public users run on Google quantum hardware?**  
No. The app is simulation-first unless approved access is configured.

**Does simulation prove business value?**  
No. Simulation is educational and useful for prototyping, not proof of advantage.
