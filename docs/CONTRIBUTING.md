# Contributing

Quantum Foundry is an independent personal project and is not an official Google product.

## Setup

Follow [LOCAL_DEVELOPMENT.md](LOCAL_DEVELOPMENT.md).

## Branch Naming

Use short descriptive branches. The Codex workflow may use `codex/` prefixes.

## PR Checklist

- Preserve independent-project disclaimers.
- Preserve hardware-access disclaimer where relevant.
- Update docs for user-visible behavior.
- Run backend tests and frontend lint/build.
- Do not commit secrets.
- Do not add non-Google quantum SDKs as a primary path.
- Do not add quantum advantage claims without strong evidence and qualification.

## Style

Use “Quantum Foundry” as the product name. Refer to Google Cloud services descriptively.
